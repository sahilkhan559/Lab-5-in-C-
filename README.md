# Lab 5: Arrays in C++

## Introduction
This lab demonstrates the use of arrays in C++ programming. An array stores multiple values of the same data type.

## Objectives
- Understand one-dimensional arrays.
- Traverse and display array elements.
- Find the maximum and minimum values.
- Implement Bubble Sort to sort elements in ascending order.

## Technologies Used
- C++
- Visual Studio Code

## Example
**Original Array:** `5 3 8 1 2`

**Sorted Array:** `1 2 3 5 8`

**Maximum:** `8`

**Minimum:** `1`

## Concepts Covered
- Array declaration and initialization
- For loops
- Maximum and minimum values
- Bubble Sort algorithm
- Output using `cout`

## How to Run
1. Open the project in Visual Studio Code.
2. Compile the C++ file using a C++ compiler.
3. Run the compiled program.
